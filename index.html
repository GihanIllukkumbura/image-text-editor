How to Edit Text on Image
1. Select ✂ Select Area tool
2. Click + drag over text to select
3. Area is covered & text box appears — type new text
💧 Pick Color — sample color from image
Double-click text box — edit text
Click text box — select (must select before deleting)
Delete or 🗑 button — remove selected text
Ctrl+D — duplicate
Ctrl+S — save as PNG
Escape — deselect / back to pointer
Ctrl+Z — undo last action
